# Órion Cash — Frontend

Interface web do Órion Cash, feita com Next.js 16, React 19 e Tailwind CSS 4.

A descrição do projeto, a arquitetura e as instruções completas estão no [README principal](../README.md).

```bash
npm install
cp .env.example .env.local   # NEXT_PUBLIC_API_URL aponta para a API
npm run dev                  # http://localhost:3000
```
